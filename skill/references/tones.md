# 대본 결(톤) 템플릿

잘 되는 쇼핑 쇼츠 계정들의 공통 구조:
**훅(0~2초) -> 공감/문제 -> 제품 정체 공개 -> 핵심 장점 2~3개(구체 숫자) -> 사용 장면 -> CTA**

공통 규칙
- 15~30초. 대사 6~9줄, 한 줄은 12~28자 정도(말로 2~3초).
- 첫 줄은 무조건 훅. "와", "이거 진짜", "~하는 분들 이거 보세요" 같이 바로 시선을 끈다.
- 원본 자막(OCR)에서 나온 사실(소재, 용량, 단계 수, 크기)만 쓴다. 없는 기능·효능을 지어내지 않는다.
- 의학적 효능, 최상급 표현("최고", "유일", "100%")은 피한다 (표시광고법).
- 강조할 단어는 `*단어*` 로 감싸면 자막에서 노란색으로 표시된다. 한 줄에 1개까지만.
- 마지막 줄 CTA는 계정 운영 단계에 맞게 고른다(아래 CTA 표).

---

## 1. 공감형 꿀템 (기본, 데모 영상 스타일)
친구에게 말하듯 "~잖아요", "~더라고요". 불편 상황 공감 -> 해결.
```
와, 여행 갈 때 *이거 하나* 챙기면 되겠는데요.
호텔 포트는 좀 꺼림직한데 뜨거운 물은 또 필요하잖아요.
텀블러처럼 생겼는데 물 넣고 버튼만 누르면 끝이에요.
앞에서 온도를 고를 수 있어서 컵라면, 커피, 차까지 다 돼요.
심지어 뚜껑이 컵이라 바로 따라 마시면 되고요.
다 쓰면 파우치에 쏙 넣어서 챙기면 돼요.
궁금하시면 댓글에 *나도* 남겨 주세요.
```

## 2. 충격 반전형
"이게 OO라고?" 로 시작해 정체를 늦게 공개.
```
이게 *전기포트*라고요?
그냥 텀블러인 줄 알았는데 물이 5분 만에 끓어요.
...
```

## 3. 비교/고발형
"아직도 OO 쓰세요?" 기존 방식의 불편 -> 대체품.
```
아직도 호텔 포트 그냥 쓰세요?
그 안에 뭘 끓였는지 아무도 몰라요.
...
```

## 4. 리스트형 (N가지)
"출장 갈 때 꼭 챙기는 것 1위" / "자취생 필수템 3가지 중 하나"
```
출장 갈 때 제가 *무조건* 챙기는 거 하나 알려드릴게요.
...
```

## 5. 상황극/1인칭 사용기
"엄마가 이거 보더니..." / "회사 동료가 어디서 샀냐고 물어본 거"
```
회사 동료가 이거 보더니 어디서 샀냐고 계속 물어봐요.
...
```

## 6. 순수 정보형 (계정 초기용, CTA 없음)
꿀팁/정보만. 판매 느낌 없이. 계정 초기 며칠 동안 이 결로 올린다.
```
호텔에서 뜨거운 물 안전하게 쓰는 방법 알려드릴게요.
...
```

## CTA 선택
| 단계 | 마지막 줄 예시 |
|---|---|
| 계정 초기 (정보형) | 없음 또는 "저장해 두고 여행 갈 때 꺼내 보세요." |
| 댓글 유도 (DM 자동발송) | "궁금하시면 댓글에 *나도* 남겨 주세요." |
| 프로필 링크 | "제품 정보는 프로필 링크에 있어요." |
| 고정 댓글 | "구매 링크는 고정 댓글에 있어요." |

## 참고 영상 "이 결로 해줘" 처리
1. `ssm new <임시프로젝트> <참고영상URL>` -> `ssm analyze` 로 화면 자막(OCR)과 콘택트시트 확보.
2. 유튜브면 yt-dlp 자동자막도 확인 가능: `.venv\Scripts\python.exe -m yt_dlp --skip-download --write-auto-subs --sub-langs ko <url>`
3. 문장 길이, 훅 패턴, 말투 어미, CTA 위치를 표로 정리한 뒤 그 구조를 그대로 따라 새 대본을 쓴다(문장 복사는 금지).
